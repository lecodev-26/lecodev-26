## 🚀 Featured Project

### 🛡️ SentinelFlow

> **Resilience infrastructure for AI agents and LLM applications.**

SentinelFlow is an intelligent gateway/proxy for AI APIs with a focus on:

- 🔀 Intelligent provider routing
- 🛡️ Automatic failover
- ⚡ Rate limiting
- 💾 Response caching
- 📊 Prometheus metrics
- 🔎 Observability & live dashboard
- 🧩 Multi-provider architecture
- 🚧 Next: retries, circuit breakers, health checks, streaming, quotas and smarter routing

**Stack:** `Go` · `HTTP` · `Prometheus` · `YAML` · `AI/LLM APIs`
