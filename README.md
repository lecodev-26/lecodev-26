## 🚀 Featured Projects

### 🛡️ SentinelFlow

**AI Gateway · LLM Routing · Failover · Observability · Go**

A production-oriented **AI Gateway and intelligent router** for multi-provider LLM infrastructure. It sits between AI applications and model providers and focuses on reliability, policy, cost-aware routing, and operational visibility.

**Stack:** `Go` `HTTP` `Prometheus` `PostgreSQL` `Redis` `YAML` `OpenAI-compatible APIs`

- 🔄 Provider failover and health-aware routing
- 🎯 Intelligent routing and policy engine
- 🚦 Rate limiting and retry policies
- 💾 Response caching and streaming
- 📊 Metrics and observability
- 🔐 Security and infrastructure controls

### 🧠 Cerebro Zero

**Autonomous Learning Cognitive Agent · AI From Scratch · Python + NumPy**

A **from-scratch cognitive AI system** built without PyTorch or TensorFlow, covering neural networks, autograd, Transformer inference, memory, planning, reinforcement learning, tokenization, tools, reproducibility, E2E evaluation, and security. Built and validated on **Android + Termux**.

**Stack:** `Python` `NumPy` `Android` `Termux`

- 🧮 Autograd and neural networks from scratch
- 🧠 Working, semantic, episodic and procedural memory
- 🤖 Cognitive agent with planning and tool use
- ⚡ Transformer with incremental KV-cache inference
- 🎯 Q-learning and reinforcement-learning experiments
- 🔤 Byte-level tokenization and BPE
- 🧪 E2E benchmarks, reproducibility and 762 tests

### 🧞 Genie

**AI Guessing Game · Akinator-style · AI Skill**

A lightweight AI skill that turns a text-based AI into an **Akinator-style guessing game**. Think of a character, animal, movie, object, place, or anything else, answer adaptive questions, and Genie tries to figure it out.

**Stack:** `Markdown` `AI Skills` `MCP`

- 🧠 Adaptive questions based on previous answers
- 🤔 Handles uncertainty such as "I don't know" and "maybe"
- 🎯 Only makes a guess when it has enough evidence
- 🔄 Supports restarting and playing multiple rounds
- 🌐 Compatible with ChatGPT, Claude, Gemini and other AI clients
